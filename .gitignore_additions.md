# Additional .gitignore Patterns

This document lists recommended `.gitignore` patterns for LiteLLM development.
These can be appended to the main `.gitignore` if not already present.

```gitignore
# Pytest
.pytest_cache/
pytest_cache/

# Coverage
htmlcov/
.coverage
.coverage.*
coverage.xml
coverage.json

# MyPy
.mypy_cache/
.dmypy.json
dmypy.json

# Ruff
.ruff_cache/

# macOS
.DS_Store
.AppleDouble
.LSOverride

# Windows
Thumbs.db
ehthumbs.db
Desktop.ini

# JetBrains IDEs
.idea/
*.iml
*.iws
*.ipr

# VS Code local settings
.vscode/settings.json
.vscode/launch.json
.vscode/extensions.json

# Local environment files
.env.local
.env.development.local
.env.test.local
.env.production.local

# Temporary files
*.tmp
*.temp
*.swp
*~

# Build artifacts
build/
dist/*.egg
*.egg-info/
```
